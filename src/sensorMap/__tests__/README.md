# Sensor map test fixtures

`docFixtures.ts` builds a small invented floor plan: three rooms, one open region and a handful of devices.
The numbers, names and Bluetooth addresses (the documentation range 00:00:5E:00:53:xx) are made up. Never
paste a real plan, device list or Bermuda dump here: this repository is public, and positions, addresses and
the times of a capture show where people live and when they are home.
